# Contributing
1. Fork repo, tạo branch `feature/<ten>`.
2. Giữ chuẩn C++17, biên dịch sạch với `-Wall -Wextra`.
3. Thêm test vào `tests/test_store.cpp` cho chức năng mới và chạy `make test` trước khi mở PR.
4. Không commit file build (`phone_store`, `run_tests`, `build/` đã có trong `.gitignore`).
